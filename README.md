# Commodity Derivatives Intelligence

Historical MCX gold futures analytics prototype. No live prices, order routing, or investment advice.

## Run
Backend: `cd backend`; `pip install -r requirements.txt`; `uvicorn app.main:app --reload`
Frontend: `cd frontend`; `npm install`; `npm run dev`
Open http://localhost:3000 and upload a Bhavcopy CSV.

## Local AI data conclusions

The **Data Conclusion** page uses Google Gemini. Configure the API key once for the backend operator in `backend/.env` (copy `backend/.env.example`, then replace the placeholder). This private file is excluded from Git. End users do not configure or receive the key; in a deployed app, set it as a secret environment variable on the backend host. Never put the key in frontend code or commit it. The Gemini Developer API free tier is subject to rate limits and availability. Free-tier prompts may be used by Google to improve its products; this prototype sends only summarized derived metrics, not the raw CSV. Set `GEMINI_MODEL` and `GEMINI_FALLBACK_MODEL` to override the primary and secondary models. All displayed conclusions are generated by Gemini; if both models fail, the page shows an actionable error and never substitutes a prewritten narrative.

The LLM only explains a compact summary of metrics already calculated by the application. It is instructed not to calculate metrics, invent market context, forecast prices, or recommend trades. The exact facts sent to the model are viewable alongside its response. Model output can still be wrong and should be checked against the displayed data. Transient Gemini errors are retried with bounded exponential backoff. If the primary model remains unavailable, the request is sent to the secondary Gemini model. There is no prewritten fallback: if both models fail, the page shows the provider error and asks the user to retry. Invalid-key and rate-limit errors remain explicit.

Data is stored locally under backend/data. No market data is fabricated. XLSX is not enabled. Contract specifications are unverified starting values from the provided specification. Backtest output is a normalized spread-return proxy in percentage points, not portfolio returns or currency P&L.
